# Лента приложения (feed.json)

Приложение раз в 6 часов скачивает `feed.json` из этого репозитория (ветка `main`)
и показывает рекламу без выпуска новой версии. Поле `support_url` — адрес службы поддержки.

Одно объявление:

| Поле | Что это |
|---|---|
| `id` | уникальный код (по нему пользователь может скрыть объявление на сутки) |
| `lang` | языки: `["ru"]`, `["en"]` или оба |
| `placements` | где показывать: `sidebar` (левая панель), `status` (главный экран) |
| `disclosure` | пометка «Реклама · рекламодатель». Для рекламы третьих лиц в РФ сюда же — ИНН/название и `erid` из ОРД |
| `title`, `text`, `cta` | заголовок, текст, надпись на кнопке |
| `url` | ссылка, только `https://` |
| `weight` | чем больше, тем чаще показывается |
| `until` | необязательно: дата окончания показа, например `2026-12-31` |

Если лента недоступна, приложение показывает встроенный блок px6.net.
