# Proxyka — downloads

**Proxyka** sends chosen Windows programs through your proxy (SOCKS5 / HTTP) and leaves the rest direct.

**Proxyka** — прокси для нужных программ Windows, остальное работает напрямую.

⬇️ **[Download the latest version / Скачать последнюю версию](https://github.com/dartygad/proxyka-releases/releases/latest)**

This repository contains only signed installers and update manifests. Installed apps update themselves from here.
