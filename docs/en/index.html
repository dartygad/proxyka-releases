A proxy for the apps you choose. Everything else goes direct.

Proxyka routes chosen Windows programs through your SOCKS5 or HTTP proxy: the browser via another country, Telegram via a proxy, banking and games as usual.

Download for Windows

Windows 10 and 11, 64-bit · free · English and Russian

Install in 1 minute

1

Run the installer

Open Proxyka-Setup.exe. If Windows shows “Windows protected your PC”, click More info → Run anyway.

2

Allow it

In “Do you want to allow this app to make changes?” click Yes — needed for the network component.

3

Done

Click Install. Proxyka opens and guides you through the setup.

Safe: Proxyka does not change Windows network settings. Interception works only while the app runs — quitting puts everything back. Uninstall removes the service, driver, firewall rule and autostart.

Three steps

1

Get a proxy

For example on px6.net — 5% off with coupon PROSTO5. Copy the host:port:login:password line.

2

Paste it

Proxyka splits the line into fields and checks that the proxy reaches the internet.

3

Choose apps

All traffic or only chosen programs. Click “Turn on”.

FAQ

How do I route only one program through a proxy?

Add your proxy, open “Programs” and click “Via proxy” next to the program. Everything else stays direct.

Is it a Proxifier alternative?

Yes — it solves the same task with a simpler setup, a wizard and px6.net import.

What if the proxy goes down?

You choose: block the connection (no leaks), go direct, or switch to a backup proxy.
